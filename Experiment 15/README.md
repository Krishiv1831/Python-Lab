## 📌 Introduction

Natural Language Processing (NLP) is a branch of Artificial Intelligence that enables computers to understand, interpret, and process human language.

Text data is unstructured in nature and requires preprocessing before analysis.

These techniques include:

-  Tokenization of text
-  Removing stopwords
-  Stemming and Lemmatization
-  Text cleaning and normalization
-  Converting text to numerical form (Vectorization)
-  Feature extraction

Python provides powerful libraries like NLTK, spaCy, and Scikit-learn for performing NLP operations.
